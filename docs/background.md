# 経緯と説明

## きっかけ

Zenn の記事「[Claude Code 並列利用のための自作ダッシュボード](https://zenn.dev/nexta_/articles/a3ff76a9f98f1c)」を読んだのが出発点。Claude Code を5〜8セッション並列で使う人が、セッションの状況を一画面で把握するために作ったダッシュボードで、特に次の点が良かった。

- 状態の札を、経過時間ではなく「誰の番か」で分けている
- カード1枚に、見出し・要約・経緯・スキル・待ち時間・閉じてよいかが収まっている
- 許可待ちは会話記録が増えないので、フックで時刻を記録して判定している
- 通知音は件数分ではなく1回だけ鳴らす

同じものを自分用に作りたい、というのが最初の動機。

## 自分が困っていたこと

記事の困りごと（どれが返事待ちか分からない、など）に加えて、一番困っていたのはこれ。

> Claude は作業中にいろいろメッセージを残してくれるが、全部読むのは大変。そのせいで、流れていった大事なことを見落とす。

途中メッセージには、

- 「仕様にないので TTL は5分にしておきました」（勝手に置いた仮定）
- 「E2E テストは環境の都合でスキップしています」（やっていないこと）
- 「本番の値を参照しないよう注意が必要です」（懸念）

のような、最後のまとめの返答から落ちやすい情報が混ざっている。レビューやマージの前に確認したいのはまさにこれ。

## このツールで足したもの

記事のカードをベースに、次の2つを足した。

1. **今ここ**：Claude の Todo の進み具合と、直近のツール呼び出し。「何分経ったか」ではなく「どこまで進んだか」が分かる
2. **拾った大事なこと**：途中メッセージから、仮定・スキップ・懸念・確認・発見の5種類を抜き出してピン留めする

詳細画面は、自分の依頼を章にした時系列で、「大事なことだけ」に絞ると、依頼に対して Claude が勝手に決めたこと・やらなかったことの一覧になる。

## 作らなかったもの（今のところ）

記事にはあるが、MVP では外したもの。

- 引き継ぎ台帳、セッションカレンダー、作業履歴、全文検索
- 使用枠の推移と予測
- Todo カレンダー

必要になったら足す。会話記録は標準設定だと30日で消えるので、検索や台帳を作るときは永続化（SQLite など）を入れる（ADR-0004）。

## 用語

| 用語 | 意味 |
| --- | --- |
| セッション | Claude Code の1回の会話。会話記録の JSONL 1ファイルに対応 |
| 章 | 自分（ユーザー）の依頼1つと、それに対する Claude の動き |
| 途中メッセージ | Claude がツール呼び出しの合間に残すテキスト |
| 返答 | 章の最後のテキスト（その後にツール呼び出しがないもの） |
| 大事なこと | 途中メッセージから抜き出した、仮定・スキップ・懸念・確認・発見 |
| 札 | 返事待ち／作業中／止まっている／区切り／終了 |
