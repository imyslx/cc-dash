# ADR-0004: ローカル完結・外部ライブラリなし・状態はメモリ上に持つ

- 状態: 採用（待ち受けアドレスについては ADR-0005 で一部置き換え）
- 日付: 2026-11-25

## 背景

自分用のツールで、会話記録には業務のコードや顧客の情報が含まれる。外に出したくないし、依存の更新に追われたくない。

## 決定

- サーバーは `127.0.0.1` だけで待ち受ける。外部サービスには送らない（Haiku 分類を有効にしたときの `claude` CLI 経由の呼び出しだけが例外）
- Node.js の標準モジュールだけで書く。画面も素の HTML / CSS / JS
- 状態はメモリ上に持ち、起動のたびに会話記録とイベントログから作り直す。永続化するのは Haiku の結果のキャッシュだけ（JSON ファイル）
- ファイルの変更検知は `fs.watch` ではなく、1.5秒ごとのポーリングで行う。画面への反映は SSE

## 理由

- 一覧に出すのは直近数日分なので、起動時に読み直してもすぐ終わる
- `fs.watch` の再帰監視は OS による差が大きい。ポーリングなら差分読み（`src/jsonl.mjs`）と組み合わせて十分軽い
- 依存がなければ、`git clone` してすぐ動く

## 見直す条件

次のどれかを作るときは、永続化（Node の `node:sqlite` など）を入れる。

- 全文検索や作業履歴（会話記録は標準設定だと30日で消えるため）
- 引き継ぎ台帳
- 使用量の集計と予測
